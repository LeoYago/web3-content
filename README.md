# Web3 Content

**Open infrastructure for digital access rights.**

Web3 Content is an open, interoperable and privacy-conscious protocol that lets cultural institutions, creators, venues and content platforms issue, verify and recognise access permissions across organisational and technical boundaries. A single digital access pass can be recognised by multiple participating services, online and in physical venues.

A WEB3HUB project · Politecnico di Milano — <https://www.web3.polimi.it/>

## This repository

The project landing page: a single static file (`index.html`, inline CSS and JS, no build step).

| File | Purpose |
| --- | --- |
| `index.html` | The landing page |
| `img/` | Partner logos (white versions for the dark theme) |
| `og-image.svg` / `og-image.png` | Social preview image (1200×630) |

## Run locally

Open `index.html` directly in a browser, or serve the folder:

```bash
npx serve .
```

then visit <http://localhost:3000>.
